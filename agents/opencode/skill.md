# OpenCode Integration Notes

Load the `webmcp` skill when implementing WebMCP Process-to-Component functionality.

Read the target application's conventions before using any template.

Templates are scaffolds only.

Adapt them to the actual project.

Keep one schema and one shared process handler.

Use document.modelContext and AbortSignal.

Do not add demo data, fallback behavior, or unrelated changes.

Preserve existing AGENTS.md and OpenCode configuration.
